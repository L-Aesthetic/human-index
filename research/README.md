# Research Notes

The Human Index is a normative framework, not a claim that every rule has already been experimentally validated. This folder is reserved for the research basis, competing views, evidence quality, and open questions behind the framework.

Before stable v1.0.0, research notes should distinguish established empirical findings, design or governance precedent, and philosophical or forward-looking arguments. A citation should not be used to make a speculative claim look empirically settled.

The bibliography is kept separate from the normative rule text so the manifesto remains readable while the evidence trail stays inspectable.
