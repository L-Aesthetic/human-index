# Contributing

The Human Index should improve when people find real failure modes, not merely accumulate principles because another slogan sounds good.

Useful contributions usually contain a concrete product behavior, institutional use, model failure, data flow, incentive, or human consequence that the current rules do not handle clearly. Explain whether the problem requires a new rule, clarification, implementation test, or counterexample.

Use the issue templates to propose a rule, challenge a rule, document a failure case, or request clarification. For normative changes, include examples, tradeoffs, and the exact language you want changed.

By contributing text, you agree that your contribution may be distributed under the repository's CC BY 4.0 license.
