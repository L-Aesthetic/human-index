# Adopters

This file records public self-declarations. Inclusion is **not certification or endorsement by Still Cloud**.

## Founding implementation

Still Cloud is developing its own product against the Human Index draft. Formal adoption will be declared against the first stable release rather than the current pre-release draft.

## Adding an organization

Open a pull request using [templates/adoption-declaration.md](templates/adoption-declaration.md) and include the organization name, version, exact product/system scope, adoption URL, declaration date, and any public exceptions.
